# Fida Zainab - Portfolio

Stack: Vite + React, Tailwind CSS v4, Framer Motion, Lucide React

## Setup & Run
1. `npm install`
2. `npm run dev`
3. `npm run build` (creates production `dist` folder)

## Contact Form (Web3Forms)
1. Get a free key at web3forms.com using `fidazainabbkk@gmail.com`.
2. Add the key to `WEB3FORMS_KEY` in `src/data.js`.
*(If left empty, it opens a Gmail draft instead).*

## Deployment
* **Vercel / Netlify:** Import repo from GitHub. Build: `npm run build`, Directory: `dist`.
* **GitHub Pages:** Run `npm run deploy` to publish to the `gh-pages` branch.

## Editing Content
* Text & data: `src/data.js`
* Styles & colors: `src/index.css`
* Profile photo: `<img />` tag in `src/App.jsx`
